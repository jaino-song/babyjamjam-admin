# SAF 관찰 진단 APK

Android 17(API 37)에서 녹음 폴더의 Storage Access Framework 동작을 관찰하는 작은 독립 진단 앱입니다. 앱은 `com.babyjamjam.helper.safspike`로 설치되며, 현재 생산용 녹음 도우미가 아닙니다.

## 빌드와 설치

JDK 17, Android SDK API 37, Gradle 9.4.1을 준비한 뒤 이 디렉터리에서 실행합니다.

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --no-daemon
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

`./gradlew`가 생성한 래퍼는 Gradle 9.4.1 바이너리를 사용합니다. SDK 루트가 기본 위치가 아니면 `ANDROID_HOME`과 `ANDROID_SDK_ROOT`를 지정합니다.

## 관찰 순서

1. **녹음 폴더 선택**에서 `ACTION_OPEN_DOCUMENT_TREE`로 테스트 트리를 고릅니다. 앱은 영구 **읽기** 권한만 저장하며 쓰기 권한을 요청하지 않습니다.
2. **지금 스캔**으로 직접 자식 문서의 이름, MIME, 크기, 수정 시각을 봅니다. 크기와 수정 시각은 공급자가 모르면 `알 수 없음`으로 표시됩니다.
3. 고정 단계(기준선, 통화 중, 통화 후, 재부팅 후, 이름 변경, 권한 해제 후)를 선택해 관찰 시점을 기록합니다. 메모 입력란은 없습니다.
4. **2초 관찰 시작**은 화면에 보이는 동안만 동작합니다. 앱이 백그라운드로 가면 즉시 중지되고 화면에 이유가 표시됩니다. 포그라운드 서비스는 사용하지 않습니다.
5. 목록에서 파일을 선택하면 **선택 파일 1바이트 읽기**가 한 번의 읽기만 수행하고 바이트를 버립니다. 오디오를 저장하거나 보고서에 넣지 않습니다.
6. **진단 JSON 내보내기**를 누르고 사용자가 고른 위치에 제한된 보고서를 기록합니다. 보고서에는 설치별 HMAC ID와 파일명 지문만 들어가며 원본 URI와 파일명은 들어가지 않습니다.

공급자가 아직 목록을 불러오는 중인 상태와 200개 표시 제한은 화면·앱 내부 이벤트·보고서에서 별도로 남습니다. 제한 여부는 201번째 행이 있는지만 확인하고, 공급자 행을 201개보다 더 읽지 않으며 전체 문서 수를 보고하지 않습니다. 디렉터리도 직접 자식 행으로 포함됩니다. 불완전 목록이나 메타데이터가 일정하다는 사실만으로 녹음 완료를 선언하지 않습니다. 이 APK에는 완료나 업로드 동작이 없습니다.

스캔과 1바이트 읽기 확인은 화면 스레드 밖에서 실행됩니다. 화면을 벗어나거나 관찰을 중지하거나 트리를 바꾸거나 권한을 해제하면 진행 중 결과를 취소하고, 세대 토큰과 선택 URI를 확인한 결과만 화면·이벤트·이전 스냅샷에 반영합니다. 기존 앱 내부 이벤트의 예전 불완전 목록 표시는 별도 원인으로 알 수 없음을 보존해 읽습니다.

2초 타이머가 샘플 스캔 중 다시 울리면 진행 중인 스캔을 취소하지 않고 해당 tick을 건너뜁니다. 샘플 결과가 반영된 뒤 다음 tick에서 새 샘플을 시작하며, 관찰 중지 시 진행 중 샘플도 무효화됩니다.

## 재시작, 재부팅, 이름 변경, 권한 해제 계획

- 프로세스를 재시작하거나 기기를 재부팅한 뒤 앱을 열고, 저장된 트리의 실제 영구 읽기 권한을 다시 확인합니다. `재부팅 후` 단계로 표시를 남깁니다.
- 공급자에서 테스트 파일 이름을 바꾼 뒤 다시 스캔하고 `이름 변경` 단계로 표시합니다. 이름 변경은 로컬 화면에서만 볼 수 있고 보고서에는 HMAC 지문으로 기록됩니다.
- 시스템 설정 또는 앱의 **이 앱의 트리 권한 해제**로 권한을 끊은 뒤 `권한 해제 후` 상태를 확인합니다. 앱은 자신이 선택한 트리 권한만 해제하고, 기존의 가명 관찰 이벤트는 보존합니다.

## 개인정보와 권한

매니페스트에는 인터넷, 마이크, 연락처, 전화, 광범위 저장소/미디어, 접근성, 서비스 권한이 없습니다. 원본 트리 URI는 앱 전용 비공개 설정과 실행 중 메모리에만 있으며 로그나 내보낸 보고서에 기록하지 않습니다. 보고서 ID와 파일명 지문은 Android Keystore의 설치별 HMAC 키로 만들고, 보고서에는 기기 모델·SDK·릴리스만 포함합니다. 앱 내부 이벤트 파일과 키는 클라우드 백업 및 기기 전송에서 제외됩니다.
