# 전체 QA 현재 상태 — 2026-09-18

전체 QA는 **미완료**다. 이 문서는 누적 기록에서 이후 검증으로 해소된 항목을 구분한 요약이다. 세부 증거는 [실행 기록](2026-09-17-production-write-pass.md), 전체 기능 목록은 [초기 감사](2026-09-17-production-audit.md)를 참조한다. 아래의 통과는 해당 시나리오만 의미하며 모든 조합·권한·기기·운영 환경의 통과를 뜻하지 않는다.

## 완료를 막는 경계와 재개 조건

- **계약/서명:** 기존 미서명 QA 문서는 보존 중이다. 취소·재발급 준비 코드는 별도 작업에 있고 현재 PR에 통합하지 않았다. DB 제약 변경 예외·경합 검증과 실행 시점 확인이 필요하다. 실제 서명·영구 삭제는 실행 직전 확인 경계를 따른다.
- **자동 발송 설정:** 규칙을 다시 켜면 기존 고객의 대기 작업을 만들 수 있다. `SCHEDULERS_ENABLED=false`만으로 안전을 증명하지 않는다. 새 미승인 지점은 UI와 서버에서 편집이 막히므로, 발신 승인된 빈 QA 지점과 작업 없음 확인이 필요하다. 새 지점 생성 양식은 취소했고 추가 지점을 만들지 않았다.
- **권한:** 지원되는 격리 인증 테스트는 PostgreSQL·Valkey·Mailpit을 사용한다. 현재 호스트에는 Docker/Podman/Colima와 Valkey가 없어 실행하지 않았다. 기존 dev DB에 인증 시드를 넣지 않았다. API 인증 테스트가 통과하더라도 역할별 실제 브라우저 검수와는 별개다.
- **브라우저:** 최신 확인에서 사용하던 Chrome QA 연결이 사라졌다. 다른 사용자 프로필로 임의 전환하지 않았다. 추가 실화면 검수에는 QA 연결 복구가 필요하다.
- **전역 작업:** 전체 기기 알림, 전체 지점에 영향을 주는 업로드·홈페이지 게시에는 격리된 대상 또는 구체적인 운영 범위가 필요하다.
- **정책/제품 기준:** 공개 약관·개인정보 경로의 인증 경계 및 정본 문서, 필수 입력 항목과 미완료 계약 집계 기준의 화면 간 차이는 확정이 필요하다.
- **운영:** 실제 기기·LAN 접근, 운영 병합·배포·재검수는 미완료다. 로컬 화면 증거를 운영 통과로 간주하지 않는다.

## 코드 및 검증 기준점

- 가격 여백·알림 이름까지 포함한 코드 기준 `edadf95ce25627789aeede3d9ef9bb8708b276c5`: Mobile CI 35305405535, Mobile Unit CI 35305405554, Shared Contracts CI 35305405527 통과. 실제 백엔드 Playwright는 건너뛰었다.
- 문서 후속 기준 `9e00fe26cf514b8deaf6c4c155b5da8eb14feef3`, PR708은 Draft다. 운영 배포하지 않았다.
- 최신 dev `19e32da34981119aa293ac7046fd0e92cfbbd764`와 7개 파일 충돌을 해결했다. Luna max의 병합 `827d8b21153ffe2b316a26e5837869cd2c777e27`과 후속 타입/테스트 보완을 포함한 최종 코드 `bb4c5b9d9f93694673f4c21270b2d9b23a770805`가 독립 FINAL SHIP/HIGH를 받았고 QA 작업 브랜치에 fast-forward 반영됐다. dev/main에는 병합하지 않았다.
- 병합 검증: 서버5324(44 skipped), 공유372, PC1860, 모바일1934 테스트 통과. PC/모바일 타입 검사, 서버·PC·모바일 빌드, lint/UI 구조/문구 검사 및 보안 점검 통과. 최초 모바일 서명 상태 테스트2개 실패는 추출된 상세 컨트롤러의 비동기 조회 응답 mock을 추가해 해결했으며 기존 상태 단언을 유지했다. 이후 모바일 전체281 suites가 통과했다. E2E 브라우저 스펙은 정적/타입 검사만 했으며 실화면 재검수와 새 CI는 별도다.

## 보존 중인 QA 데이터

- 기존 QA 고객·제공인력 및 문서·문자 기록은 검수 증거로 유지한다.
- 모바일 등록용 비활성 지점에는 고객165와 실패한 내부 자동화 복구 의도 1건이 남아 있다. 이는 발송완료나 외부 발송 예약 증거가 아니다. 이후 지점 재활성화와 발신 승인 시 이 기록을 고려해야 한다.
- 비밀키, 공개 링크 토큰, 로그인 값은 이 문서에 기록하지 않는다.
