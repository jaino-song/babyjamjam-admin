# 고객·계약 상세 검수 목록 — 2026-09-17

## 이 목록의 의미

소스 조사로 확장한 **미완료 검수 목록**이다. 일부 화면/입력 분기의 실행 증거는 검수 원장에 별도로 기록했다. 표의 행은 케이스 묶음이며 통과 건수나 검수율이 아니다.
각 묶음 안의 조작·오류·권한·장치 조건을 실제 실행할 때 하위 ID를 부여하고,
대상 배포 SHA, QA entity ID, 입력, 예상/실제 결과, 화면·재조회 근거를 따로 남긴다.
전체 서비스 목록은 [검수 원장](2026-09-17-production-audit.md)에 있다.

조사 대상은 작업 브랜치의 고객·계약 소스이며 배포 기준 `bcb3277cbb0c67943104e354baa321969a89e287`과 비교했다.
현재 작업 소스는 신규 생년월일을 `YYYY-MM-DD`로 입력하고, 해석 가능한 기존 6자리 값은 읽을 때 정규화한다.
관찰 당시 배포는 이전 6자리 입력이다. 이 차이를 배포 회귀로 오판하지 않는다.
모바일 고객 상세의 영수증 발송 메뉴도 작업 소스에만 추가되어 있다.

실행 공통 조건:

- QA 지점·고객·직원·계약만 변경한다. 연락처는 대화에서 승인된 수신처만 사용하며 이 문서에 적지 않는다.
- 실제 데이터 저장 → 목록/상세 재조회 → 새로고침 → 다른 기기의 재조회를 구별한다.
- 발송 요청, 앱 성공 이력, 제공업체 처리, 실제 수신은 각각의 근거가 필요하다.
- 취소·삭제·서명·링크 초기화는 해당 QA 대상과 영향을 확인하고 수행한다.
- 오너·지점장·직원·비로그인과 지점 간 접근을 별도 하위 케이스로 실행한다.
- 정상·빈값·잘못된 값·느린 응답·실패·재시도·중복 클릭·뒤로가기·미저장 취소를 구분한다.

## 실행 상태와 남은 준비 — 2026-09-18 갱신

사용자 승인으로 프로덕션 QA 지점을 일시 활성화해 제공인력 149 생성·수정·원복을 확인했고, 종료 시 비활성으로 원복했다. 최신 근거는 [운영 쓰기 검수 기록](2026-09-17-production-write-pass.md)에 있다.
