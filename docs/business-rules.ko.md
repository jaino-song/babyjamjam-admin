# 업무 규칙 (Business Rules) — 단일 기준 문서

이 문서는 앱이 **무엇을 사실로 보고, 무엇을 허용하고, 무엇을 금지하는지**의 단일 기준(SOT)이다.
코드·화면·자동화가 이 문서와 다르면 **코드가 버그**다. 규칙을 바꾸려면 이 문서를 먼저 고친 뒤 코드를 맞춘다.

- 기준일: 2026-10-12 (dev `f38f907b6` 기준 코드 조사 + 사용자 결정 2026-10-09, 2026-10-12 4차 확인)
- 2026-10-12 확정 사항의 구현은 BJJ-431과 그 하위 이슈(BJJ-432~448)에서 한다. "구현: BJJ-xxx"는 규칙은 확정됐고 코드가 아직 따라오지 않았다는 뜻이다.
- 상태 표기: **확정** = 사용자가 결정했거나 현재 코드가 의도대로 구현함 · **결정 필요** = 사용자 결정 대기(권고안 병기) · **위반** = 규칙은 확정이나 코드가 어김(연결된 Linear 이슈에서 수정)
- 위반 이슈는 2026-10-09 전수 스윕(BJJ-362, 보고서: "스윕 통합 보고서 2026-10-09")의 패키지 번호(Pxx)와 Linear 번호(BJJ-xxx)로 표기한다.
